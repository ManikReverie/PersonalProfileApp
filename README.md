# Project Overview
This is a Personal Profile App built for Android. It displays personal information including a profile picture, name, email, phone number, and a short biography.

# Technologies Used
- Kotlin
- Android XML Layouts
- Android SDK

# Features
- Scrollable profile view
- Displays profile picture
- Shows contact information (email, phone number)
- Includes a short bio

# How to Run
1. Clone or download the repository.
2. Open Android Studio.
3. Select "Open an Existing Project" and choose the `PersonalProfileApp` folder.
4. Wait for Gradle to sync the project.
5. Build and run the app on an Android emulator or a physical device connected via USB/Wi-Fi.

# Outcome
The application will launch and present a neatly formatted, centered personal profile. The user can scroll if the content exceeds the screen height.
